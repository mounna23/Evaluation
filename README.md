### Applications Java — Hibernate / JPA
Cette évaluation trois mini-applications Java illustrant la gestion de données avec Hibernate et une architecture en couches (Persistance / Service).
Chaque exercice met en œuvre la création d’entités, l’utilisation de requêtes HQL, Criteria et nommées, ainsi que la manipulation de données via des services spécialisés.
## Exercice 1 — Gestion de stock
Application permettant de gérer les produits, catégories, commandes et lignes de commande d’un magasin informatique.
Inclut des requêtes pour filtrer les produits par catégorie, par commande, ou par prix.

## Exercice 2 — Gestion de projets
Application de suivi de projets pour un bureau d’études.
Permet d’afficher les tâches planifiées, réalisées et leurs coûts, ainsi que les projets gérés par chaque employé.

## Exercice 3 — Gestion de l’état civil
Application simulant la gestion des citoyens et des mariages dans une province.
Gère les hommes, femmes, mariages et enfants, avec requêtes avancées (HQL, natives, Criteria) pour analyser les relations familiales.
